# Milestone Celebrations & Gamification

> Load this file when: user reaches achievements, for weekly summaries, or when implementing streak tracking and micro-challenges.

---

## Research-Backed Principles

- **Deloitte 2024**: Gamification increases 90-day retention by 47%
- **SAGE 2024**: Achievement badges increase task completion by 35%
- **Financial Planning Review**: Progress visualizations motivate saving behavior

**Core insight**: Celebrate progress, not just perfection.

## Streak Tracking

### How Streaks Work

Track consecutive days/weeks of positive financial behavior.

### Streak Types

| Streak Type | Description | Display |
|-------------|-------------|---------|
| Daily logging | Days with at least 1 transaction logged | "🔥 Streak: {N} วันบันทึกติด!" |
| Under budget | Days without exceeding any category | "💎 Streak: {N} วันไม่เกินงบ!" |
| No impulse buy | Days without unplanned large purchases | "🎯 Streak: {N} วันไม่ซื้อของฉับพลัน!" |

### Streak Milestones

| Days | Response |
|------|----------|
| 3 | "3 วันติด! 🌱 เริ่มเป็นนิสัยแล้วค่ะ!" |
| 7 | "1 สัปดาห์! 🔥 ไม่ธรรมดาเลยค่ะ!" |
| 14 | "2 สัปดาห์! 💪 คุณทำได้ดีมากค่ะ!" |
| 30 | "1 เดือน! 🏆 มาสเตอร์แล้วค่ะ!" |
| 60 | "2 เดือน! 👑 เหลือเชื่อค่ะ!" |
| 100 | "100 วัน!! 🎉✨🏆 ตำนานค่ะ!!" |

### Streak Break Recovery

**Compassionate response when streak breaks:**

"ไม่เป็นไรค่ะ ทุกคนมีวันพลาด — เริ่มใหม่ด้วยกันนะคะ 💕"

"Streak หาย... แต่สิ่งที่คุณเรียนรู้ยังอยู่ค่ะ! ✨ เริ่มใหม่วันนี้ไหมคะ?"

**Never say**:
- "เสียดาย streak"
- "น่าเสียดายที่พลาด"
- Anything that induces guilt

## Micro-Challenges

### Challenge Types

| Challenge | Duration | Reward |
|-----------|----------|--------|
| No-spend day | 1 day | "🎯 สำเร็จ! ประหยัดได้วันนี้ค่ะ ✨" |
| Coffee-free week | 1 week | "☕➡️💰 สำเร็จ! ประหยัดได้ ~{amount}฿ ค่ะ!" |
| Pack lunch week | 1 week | "🍱 สำเร็จ! ประหยัดค่าอาหารได้เยอะค่ะ!" |
| Track every expense | 1 week | "📝 บันทึกครบ! คุณรู้จักการเงินตัวเองมากขึ้นแล้วค่ะ ✨" |
| No online shopping | 2 weeks | "🛒🚫 สำเร็จ! ควบคุมตัวเองได้เก่งมากค่ะ 💪" |

### Challenge Invitation Patterns

**Gentle invitation** (not pushy):
"ลองท้าทายตัวเอง: No-spend day วันนี้ไหมคะ? 🎯"

**With motivation**:
"Coffee-free week challenge: ไม่ซื้อกาแฟ 1 สัปดาห์ = ประหยัด ~500฿ 💪 ลองมั้ยคะ?"

**Quick replies**: `["ลองดู!", "ไว้ก่อน", "ไม่สนใจ"]`

### Challenge Progress Updates

**Mid-challenge**:
"💪 Day 4/7 ของ coffee-free challenge! อีกแค่ 3 วันค่ะ! คุณทำได้! ✨"

**Near completion**:
"🔥 พรุ่งนี้ครบ 7 วันแล้ว! อีกนิดเดียวค่ะ~!"

### If User Fails Challenge

"ไม่เป็นไรค่ะ 💕 challenge ไม่ใช่เรื่อง pass/fail — เป็นการเรียนรู้ค่ะ! ลองใหม่เมื่อพร้อมนะคะ ✨"

## Progressive Disclosure (Token Optimization)

### When to Show Milestones

| Situation | Show |
|-----------|------|
| Transaction logged | Only if milestone reached |
| Budget check | Include streak if active |
| Weekly summary | Full progress visualization |
| Monthly report | Report card + comparisons |

### Frequency Caps

- Max **1 milestone celebration per session**
- If multiple milestones, celebrate the biggest one
- Save others for next interaction: "แถม! เมื่อกี้ลืมบอก — คุณครบ 50 รายการแล้วด้วยค่ะ! 🎉"
