# ThaiFin Pro — Conversation Flow Examples

Reference examples showing expected conversation patterns for each feature.

---

## Quick Expense

```
User: "จ่าย 200 กาแฟ"
Bot: ✨ บันทึกแล้วค่า~: ☕ กาแฟ 200฿
     งบอาหารเหลือ 1,800฿ สู้ๆ นะคะ! 💪
```

```

     งบเดินทางเหลือ 880฿ เก่งมากค่ะ! 🌟
```

## View Transactions

```
User: ดูรายจ่ายวันนี้

     🍜 ข้าว 80฿ (12:45) 👥 BaiY

     รวม: 295฿ ✨
     ขยันบันทึกมากเลยค่า~! 💕
```

## No Transactions Today

```
User: ดูรายจ่ายวันนี้
Bot: ยังไม่มีรายจ่ายวันนี้นะคะ 🎉 ออมเก่งมาก! ✨
```

## Delete Last Transaction

```
User: ยกเลิกรายการล่าสุด
Bot: ✨ ยกเลิกแล้วค่า~: ☕ กาแฟ 65฿ (9:30)
     ไม่เป็นไรนะคะ! 🌟
```

## Delete (No Transactions)

```
User: undo
Bot: ไม่มีรายการให้ยกเลิกค่ะ~ ไม่เป็นไรนะคะ! 🌟
```

## Split Expense

```
User: แชร์ค่าอาหาร 500 กับ Mik
Bot: ✨ แชร์แล้วค่า~: 🍜 ค่าอาหาร 500฿
     คุณ: 250฿ (จ่ายแล้ว) ✓
     Mik: 250฿ (ยังไม่จ่าย)
     เก่งมากที่แชร์กันค่ะ! 🎉
```

## Split with Multiple People

```
User: หารค่าแกร็บ 300 กับ Mik, Ta
Bot: ✨ แชร์แล้วค่า~: 🚕 ค่าแกร็บ 300฿
     คุณ: 100฿ (จ่ายแล้ว) ✓
     Mik: 100฿ (ยังไม่จ่าย)
     Ta: 100฿ (ยังไม่จ่าย)
     แชร์กันยิ่งใหญ่! 💕
```

## Split (No Group)

```
User: แชร์ 200 กับ John
Bot: อ๊ะ! คุณยังไม่มีกลุ่มค่ะ~ สร้างกลุ่มในแอปก่อนนะคะ แล้วมาแชร์กันได้เลย! 💕
```

## Split (Member Not Found)

```
User: แชร์ 200 กับ John
Bot: อ๊ะ! ไม่พบ 'John' ในกลุ่มค่ะ~ ลองเช็คชื่อใหม่นะคะ! 🔍
```

## Check Debts

```
User: ใครเป็นหนี้ใคร
Bot: 💰 ยอดค้างชำระค่ะ

     เขาเป็นหนี้คุณ:
       Mik: 250฿ (BaiY & Mik)

     คุณเป็นหนี้:
       Ta: 100฿ (Trip Japan)

     สรุป: +150฿ ✨
     เดี๋ยวเคลียร์กันได้ค่ะ! 💪
```

## Settle Debt

```
User: จ่าย Mik แล้ว
Bot: 🎉 ยอดเยี่ยม! ชำระหนี้แล้วค่า~: Mik 450฿
     (3 รายการ)
     เคลียร์กันเรียบร้อย สบายใจได้เลยค่ะ! ✨
```

## Check Bills

```
User: บิลอะไรใกล้ครบกำหนด
Bot: 📅 บิลที่ต้องจ่ายค่ะ

     ⚠️ เกินกำหนดแล้วนะคะ:
       📱 ค่าไฟ 1,200฿ (เกิน 1 วัน)

     กำลังจะถึง:
       📱 ค่าเน็ต 599฿ (อีก 6 วัน)

     รวมที่ต้องจ่าย: 599฿
     อย่าลืมจ่ายนะคะ! 💪✨
```

## Simplified Debt Query

```

       → BaiY: 150฿ (Roommates)

     คนอื่นต้องจ่ายคุณ:
       ← Som: 80฿ (Trip Japan)

     💡 ลดจาก 5 เป็น 2 รายการ! เก่งมาก~
     สรุป: +70฿ ✨
     เคลียร์กันเร็วๆ นะคะ! 💪
```

## Notification Settings

```
User: ตั้งค่าแจ้งเตือน
Bot: 🔔 การตั้งค่าแจ้งเตือนค่ะ

     งบประมาณ: เปิด (แจ้งเมื่อใช้ 80%)
     บิล: เปิด (แจ้งก่อน 3 วัน)
     สรุปรายสัปดาห์: เปิด

     อยากเปลี่ยนอะไรบอกได้เลยนะคะ~ 💕
     เช่น "ปิดแจ้งเตือนบิล" หรือ "เตือนตอน 8 โมง"
```

## Update Notification Settings

```
User: ปิดแจ้งเตือนบิล
Bot: ✅ อัพเดทแล้วค่า~: ปิดแจ้งเตือนบิล
     เปลี่ยนกลับเมื่อไหร่ก็บอกนะคะ! 🌟
```

## Set Custom Notification Time

```
User: เตือนตอน 8 โมงเช้า
Bot: ✅ ตั้งเวลาเตือนเป็น 8:00 น. แล้วค่ะ
     คุณจะได้รับการแจ้งเตือนทุกวันเวลา 8:00 น.
```

## Multi-Reminder on Financial Event

```
User: บันทึกสินเชื่อรถ 467 บาท ทุกวันที่ 28 เตือนตอน 13:30 ถามว่าเงินเดือนเข้าไหม
Bot: ✨ บันทึกสินเชื่อรถแล้วค่า~ 467฿/เดือน
     📅 ชำระทุกวันที่ 28
     🔔 เตือนเวลา: 13:30 น. - "ถามว่าเงินเดือนเข้าไหม"
     สู้ๆ นะคะ! 💪

User: เพิ่มเตือนเวลา 14:00 ให้ฝากประจำ
Bot: ✅ เพิ่มเตือนแล้วค่า~ 🎉 คุณจะได้รับการแจ้งเตือน 2 ครั้ง:
     - 13:30 น. ถามว่าเงินเดือนเข้าไหม
     - 14:00 น. ฝากประจำ
```
